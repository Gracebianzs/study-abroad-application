# 匹配度打分框架

## 一、评分维度与权重

对每所候选院校，从以下6个维度进行10分制评分，加权计算综合匹配度：

| 维度 | 权重 | 评分说明 |
|------|------|---------|
| 学术背景匹配 | 20% | 本科专业对口度、GPA是否达到要求、院校层次是否被认可 |
| 语言成绩达标 | 15% | 雅思/托福总分和小分是否满足要求，超出程度 |
| 学费预算匹配 | 20% | 学费是否在用户预算内，超出幅度 |
| QS排名 | 15% | 院校QS世界排名，排名越高得分越高 |
| 录取概率 | 15% | 基于历史录取数据和用户背景评估的录取可能性 |
| 项目质量 | 15% | 项目学术声誉、课程设置、职业发展支持、师资力量 |

**综合得分 = 学术匹配×0.20 + 语言达标×0.15 + 学费匹配×0.20 + QS排名×0.15 + 录取概率×0.15 + 项目质量×0.15**

## 二、各维度评分标准

### 2.1 学术背景匹配（20%）

| 得分 | 标准 |
|------|------|
| 9-10 | 专业完全对口（如英语/语言学/教育学），GPA远超要求（≥85/3.5），本科院校被高度认可（985/211/海外名校） |
| 7-8 | 专业相关或可接受，GPA达到要求，本科院校被认可 |
| 5-6 | 专业部分相关，GPA刚好达到最低要求，本科院校一般 |
| 3-4 | 专业不太对口但可申请，GPA略低于建议但达到最低 |
| 1-2 | 专业不对口或GPA不满足最低要求 |

### 2.2 语言成绩达标（15%）

| 得分 | 标准 |
|------|------|
| 9-10 | 总分和所有小分均远超要求（如要求7.0，实际7.5+） |
| 7-8 | 总分和所有小分均满足要求，有一定余量 |
| 5-6 | 总分满足但小分刚好达标，或总分刚好达标 |
| 3-4 | 总分满足但某项小分未达标（可重考补救） |
| 1-2 | 总分未达标 |

**注意**：小分要求（尤其是写作）是关键筛选条件，必须单独评估。如港中文/港科大要求写作≥7.0。

### 2.3 学费预算匹配（20%）

| 得分 | 标准 |
|------|------|
| 9-10 | 学费远低于预算（≤预算70%） |
| 7-8 | 学费在预算内（≤预算100%） |
| 5-6 | 学费略超预算（预算100%-110%） |
| 3-4 | 学费超预算较多（预算110%-130%） |
| 1-2 | 学费远超预算（>预算130%） |

**一票否决参考**：如用户明确要求学费严格在预算内，超预算院校需在报告中明确标注，但仍可纳入分析供用户决策。

### 2.4 QS排名（15%）

| 得分 | QS排名区间 |
|------|-----------|
| 9-10 | 全球前20 |
| 7-8 | 全球21-50 |
| 5-6 | 全球51-100 |
| 3-4 | 全球101-200 |
| 1-2 | 全球200+ |

### 2.5 录取概率（15%）

| 得分 | 标准 |
|------|------|
| 9-10 | 录取率>60%，用户背景远超典型录取背景 |
| 7-8 | 录取率40%-60%，用户背景优于典型录取背景 |
| 5-6 | 录取率20%-40%，用户背景符合典型录取背景 |
| 3-4 | 录取率10%-20%，用户背景略低于典型录取背景 |
| 1-2 | 录取率<10%，用户背景明显低于典型录取背景 |

**录取概率评估依据**：
- 学校公布的中国学生录取数据（如有）
- 留学平台公布的offer案例和录取背景统计
- 用户背景与典型录取背景的对比（院校层次、GPA、语言、实习/科研）
- 项目竞争激烈程度（申请量、招生人数、是否有笔面试）

### 2.6 项目质量（15%）

| 得分 | 标准 |
|------|------|
| 9-10 | 学科排名全球前20，项目历史悠久，师资顶尖，职业服务完善 |
| 7-8 | 学科排名全球21-50，项目口碑好，课程设置合理 |
| 5-6 | 学科排名全球51-100，项目质量中等，有一定特色 |
| 3-4 | 学科排名100+，项目较新或口碑一般 |
| 1-2 | 项目质量较差或信息严重不足 |

**项目质量评估参考**：
- QS教育学学科排名 / Times Higher Education教育学科排名
- 项目开设历史和招生规模
- 核心课程与用户兴趣方向的匹配度
- 是否有教学实践/实习机会
- 毕业生就业数据和校友网络
- 师资力量（教授数量、研究方向）

## 三、投递定位分类

根据综合得分和录取概率，将院校分为三类：

| 定位 | 综合得分 | 录取概率 | 建议数量 |
|------|---------|---------|---------|
| 冲刺(Reach) | ≥8.0 | <50% | 1-2所 |
| 主申(Match) | 7.0-8.5 | 50%-70% | 2-3所 |
| 保底(Safety) | 6.5-7.5 | >70% | 1-2所 |

**建议总投递数量**：5-8所，避免过多分散精力，也避免过少风险集中。

## 四、打分输出格式

每所院校的评分结果以表格形式呈现：

| 院校 | 学术匹配 | 语言达标 | 学费匹配 | QS排名 | 录取概率 | 项目质量 | 综合得分 | 定位 |
|------|---------|---------|---------|--------|---------|---------|---------|------|
| 示例大学 | 9.0 | 8.0 | 9.5 | 8.5 | 7.0 | 9.0 | 8.6 | 主申 |

综合得分保留1位小数，按综合得分降序排列。

## 五、注意事项

1. **打分主观性**：录取概率和项目质量包含主观判断，应在报告中说明评分依据
2. **数据时效性**：录取率数据标注年份，不同年份波动可能较大
3. **个体差异**：打分基于用户整体背景，实际录取还受文书质量、推荐信、面试表现等因素影响
4. **动态调整**：如用户背景发生变化（如雅思重考、新增实习），应重新打分
5. **预算硬约束**：如用户明确表示不接受超预算院校，学费匹配维度可作为一票否决项
